# 💧 HydroQuest Jr. — Wetman & Watershed Puzzle Edition

A friendly, animated entry-level game that introduces the water cycle and
basic engineering hydrology. Built as a single HTML file — no installation,
works in any browser on any device.

## 🎮 Play Now

**▶ [Play HydroQuest Jr.](https://karim-sherif-mostafa.github.io/hydroquest-jr.html/)**

## 🧩 How It Works

An empty landscape waits to be restored. Each correct answer **pops one
animated piece** into place — ten pieces in total:

☀️ Sun → ☁️ Clouds → 🌧️ Rain → ⛰️ Mountains → 🏞️ River → 🌲 Trees →
🚧 Dam → 🌡️ Gauge Station → 🏙️ City → 📈 Hydrograph Monitor

A cute droplet character (the **Wetman**) cheers you on — but every wrong
answer costs one of your 5 water drops. Lose them all and he dries out!
(Friendly instant retry, no harsh game-over.)

## 📚 Topics Covered

| # | Question | Concept |
|---|----------|---------|
| 1 | Water cycle sequence | Evaporation & condensation |
| 2 | Cloud formation | Condensation |
| 3 | Tipping-bucket gauge | Rainfall depth = tips × 0.2 mm |
| 4 | Depth → volume | V = P × A × 1000 |
| 5 | Rational Method | Q = CiA/3.6 |
| 6 | SCS Curve Number | Retention S = 25400/CN − 254 |
| 7 | Reservoir balance | ΔS = In − Out − Evaporation |
| 8 | Kirpich equation | Time of concentration |
| 9 | Water balance | P = R + ET + ΔS |
| 10 | Return period | P = (1 − 1/T) × 100 % |

## ✨ Features

- 🎨 **Fully animated scene** — falling rain, flowing river, drifting clouds
- 🔢 **Instant feedback** with worked solutions after each answer
- 💧 **Wetman lives system** — 5 attempts per run, gentle retry
- ⭐ **Scoring** with star-friendly points
- 📱 **Responsive** — phones, tablets, desktops
- 💾 Progress saved during the session; replay for a new run

## 🎯 Intended Use

Ideal as an **ice-breaker or warm-up** for first-year hydrology,
a **pre-class primer**, or a **fun revision break** before exams.
Also great projected on screen for whole-class play.
